# ShellX Cut public documentation

Everything in this directory is part of the supported source documentation and
may also be bundled with the installed application. Keep links, commands, and
feature descriptions self-contained and usable from a fresh checkout.

- `FEATURES.md` is the public feature inventory.
- `DEBUG_API.md` documents local Debug API and MCP control.
- `FEATURE_CHANGE_WORKFLOW.md` is the contributor feature checklist.
- `BUILDING.md` and `TEST_RIGS.md` cover public build and verification steps.
- `SHELLX_MOTION_BOUNDARY.md` defines the Cut and Motion integration boundary.
- `site/` contains the public manual source.

Repository-local working notes may use the ignored `docs/private/` directory.
