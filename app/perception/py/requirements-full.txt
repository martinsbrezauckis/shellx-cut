# ShellX Cut perception sidecar — FULL perception extras policy.
#
# `perception_setup.rs` installs this bundled policy directly after the required
# onnx-asr base with:
#   uv pip install --only-binary :all: --torch-backend cpu --strict \
#     -r requirements-full.txt
#
# uv resolves current compatible wheels when the user consents to setup. We do
# not ship a generated platform lock because that turns ordinary dependency
# updates into Cut releases. The setup receipt records the actual resolved
# package versions, and `uv pip check` must pass before extras are ready.
#
# WHY THESE FLAGS:
#   --only-binary :all:  → NEVER compile from source on a user box (no MSVC/LLVM).
#                          If a wheel is genuinely missing, the full tools remain
#                          unavailable and the base transcription engine still works.
#   --torch-backend cpu  → uv selects official CPU torch-family wheels while normal
#                          dependencies keep their regular index policy. This avoids
#                          CUDA/NVIDIA payloads without unsafe multi-index matching.
#   numpy<2.5 (below)    → KEEPS numba on its newest prebuilt WHEEL (numba 0.65.x
#                          requires numpy<2.5). Without this proven bound, the
#                          resolver can select an sdist-only numba/llvmlite route.
#
# If these extras fail to resolve or pass dependency checking, transcription STILL
# works from the base. instruments.py imports extras lazily and falls back to the
# ffmpeg-based instruments when an extra is absent.
#
numpy<2.5             # BSD-3 — PIN: hold numba/llvmlite on their prebuilt wheels (see header)
#
# ── FALLBACK transcription (only used when onnx-asr is absent/errors) ──────────
whisperx              # BSD-2 — word-level timestamps fallback (pulls faster-whisper, torch)
torchaudio            # BSD-2 — MMS_FA forced alignment for Canary word timestamps
silero-vad            # MIT — voice activity detection
soundfile             # BSD-3 — WAV reader for Silero silence analysis
transformers          # Apache-2.0 — local text translation fallback (Marian/MADLAD)
sentencepiece         # Apache-2.0 — tokenizer runtime required by Marian/Opus-MT
scenedetect           # BSD-3 — PySceneDetect content detector (0.7 bundles opencv-python)
torchvision           # BSD-3 — SSDlite-MobileNetV3 / Faster R-CNN detector for the
                      # on-demand `subject` instrument (auto-reframe). Rides the torch
                      # whisperx pulls and keeps the optional detector stack BSD-licensed.
supervision           # MIT — ByteTrack multi-object tracker (Roboflow), pairs with the
                      # torchvision detector for stable subject ids across frames.
mediapipe             # Apache-2.0 — Tasks FaceDetector for FACE-AWARE framing in the
                      # `subject` instrument (blaze_face_short_range.tflite bundled
                      # beside instruments.py). GRACEFUL: absent → body+saliency framing.
rapidocr-onnxruntime  # Apache-2.0 — OCR for redaction auto-detect (edit.redact{ocr_auto}).
                      # RIDES onnxruntime (NO torch / NO paddle); bundles PP-OCR ONNX
                      # det+rec models (~14 MB, fetched once on first run).
