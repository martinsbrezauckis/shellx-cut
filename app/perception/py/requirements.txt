# ShellX Cut perception sidecar - BASE transcription dependencies.
# Permissive licenses only. Provisioned by perception_setup.rs with uv pip
# install --only-binary :all: --strict -r requirements.txt into a standalone
# CPython 3.12 venv; system Python on real desktops can be too old.
#
# BASE policy: this install stays wheel-only so fresh user machines need no
# compiler. It installs the CPU ONNX engine, Hub client, and the direct audio
# and numerical modules used by the base word/beat routes; model files are
# prepared later into the app-owned perception directory and are reported
# separately from package import readiness. Torch-based extras remain in
# requirements-full.txt and are best-effort.
#
# PRIMARY transcription engine
# NVIDIA Parakeet-TDT-0.6B via ONNX Runtime - native, accurate word timestamps,
# punctuation and caps, with no torch. cpu selects the ONNX Runtime CPU build;
# hub supplies the canonical local-directory model preparation. macOS forces
# the CPU EP at runtime because CoreML fails on the model external-data init.
# onnx-asr resolves its canonical Hub model mapping and local-dir resume flow.
# uv resolves a current compatible release at consent time; the model still
# has to load successfully before transcription is ready.
